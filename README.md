# Art Epoch Explorer

ich möchte eine App erstellen, mit der mann alles über künstler lernen kann also maler, sagen wir zB man lernt etwas über den maler und die werke des malers, es sollte nach epochen kategorisiert sein, man sollte die Werke sich anschauen können und eine kurze beschreibung dazu haben, es sollte schön geordnet sein in einem clean look, chrom weiß, modern.
